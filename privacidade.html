Política de Privacidade

Última actualização: 30 de Agosto de 2026

Resumo: A sua privacidade é importante. Recolho apenas os dados necessários para comunicação e prestação de serviços. Não vendo informações a terceiros.

1. Quem sou

Este portfólio e os serviços associados são prestados por Adamgy Adamo Tembe, com base em Pemba, Moçambique. Sou o único responsável pelo tratamento dos dados recolhidos.

2. Dados que recolho

Recolho apenas os dados estritamente necessários:

  • Nome e email — quando me contacta através do formulário ou email
  • Número de telefone — para comunicação sobre serviços contratados
  • Dados de navegação anónimos — contador de visitas (localStorage, não identificável)

2.1 Dados que NÃO recolho

  • Não utilizo cookies de rastreamento de terceiros
  • Não recolho dados de cartão de crédito
  • Não recolho dados de localização GPS
  • Não acedo a ficheiros pessoais do seu dispositivo

3. Como uso os seus dados

  • Para responder aos seus contactos e orçamentos
  • Para comunicar sobre serviços contratados
  • Para melhorar o conteúdo deste portfólio

4. Partilha de dados

Não vendo nem partilho os seus dados pessoais com terceiros, excepto quando legalmente obrigado.

5. Segurança

Este site utiliza HTTPS para encriptação em trânsito. O dashboard administrativo utiliza autenticação local e os dados são armazenados apenas no seu navegador (localStorage).

6. Os seus direitos

Tem direito a solicitar acesso, rectificação ou eliminação dos seus dados.

7. Alterações a esta política

Poderei actualizar esta política periodicamente. Alterações significativas serão comunicadas nesta página.
