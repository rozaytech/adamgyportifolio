# adamgy.vmpsaas.com

Portfólio profissional de **Adamgy Adamo Tembe** — Engenheiro de Software e Especialista em Infraestruturas de Rede, baseado em Pemba, Moçambique.

## Sobre

Este repositório contém o código-fonte do meu portfólio pessoal, hospedado em `adamgy.vmpsaas.com`. O site foi construído com HTML, CSS e JavaScript vanilla — sem frameworks pesados, focado em performance e simplicidade.

## Tecnologias

- HTML5 semântico
- CSS3 (Grid, Flexbox, variáveis CSS)
- JavaScript vanilla (Canvas API, Intersection Observer)
- PWA (Service Worker, Manifest)
- Chart.js (painel administrativo)
- jsPDF (exportação de relatórios)
